# Why there is no application front end

The recurring work is inspecting a catalogue, applying documented rules, fixing exceptions and reviewing the next output. One database and one CLI keep that work reproducible. Generated HTML provides read-only reviews and printable paperwork.

A screen gives you visual rule editing, drag-and-drop mapping, quick catalogue browsing and live dashboards. This base does not provide those interactions, mobile editing, offline synchronisation or a hosted feed URL. Enterprise DNA can build the screens and connections the business needs into its version.

The database is the product. Claude Code, Codex, OpenCode and Cursor are ways to operate it. No agent-specific fork is needed.
